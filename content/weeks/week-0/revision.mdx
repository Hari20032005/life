## Week 0 revision notes

<Callout kind="keypoints">

- URL → DNS → TCP → TLS → HTTP → server/CDN → HTML → DOM+CSSOM → layout → paint.
- fetch resolves on HTTP errors: always check `response.ok`.
- Never trust user text: `textContent`, not `innerHTML`.
- One delegated listener, not one per item.
- Every widget has loading, error, empty and data states.
- Write up every bug: symptom → cause → fix → how verified.

</Callout>
