## Week 6 cheat sheet

### Discovery call (30 min)
Context 5 · Current workflow 10 · Pain and cost 5 · Constraints 5 · Success metrics 5 · read back and confirm.

### Problem statement fields
Client · their words · current workflow · baseline numbers · constraints · measurable success criteria · out of scope · assumptions · sign-off.

### Architecture doc sections
Goals · diagram (each box justified in one line) · data model · API · AI components · hosting/deploy · monthly cost (formula + sources) · risks and SPOFs · out of scope · task plan.

### Task format for an AI agent
`Objective · files/constraints · done condition (checkable) · tests to add`. One small PR each; main stays deployable.

### Change-request reply
Restate need → impact on scope/time/cost/risk → options (now / smaller now / v2) → recommendation → ask for written decision → update scope.

### AI patch review
Read the whole diff · were tests edited? · security-sensitive code touched? · behaviour beyond the ask? · run and mutate tests · write a regression test · explain every line.

### Handover pack
README (local vs deployment) · ARCHITECTURE · API · RUNBOOK · KNOWN-LIMITS · COST · AI section · demo video.
